# Product Roadmap

## MVP — Current

### Goal
Create a working AI study assistant that can answer students' questions.

### Key Features
- User enters a study question.
- User clicks the "Ask AI" button.
- AI generates an explanation.
- The answer is displayed to the user.

### Success Criteria
A user can enter a question and receive a meaningful AI-generated answer without an error.

---

## Alpha

### Goal
Improve the learning experience with additional study features.

### Key Features
- AI-generated summaries.
- AI-generated practice questions.
- Different explanation levels.
- Improved user interface.

### Success Criteria
A user can receive an explanation, summary, and practice questions for a selected topic.

---

## Beta

### Goal
Introduce user accounts and study history.

### Key Features
- User registration and login.
- Save previous questions.
- Study history.
- Personal dashboard.

### Success Criteria
A registered user can log in and access their previous study activities.

---

## Final Release

### Goal
Provide a complete personalized AI learning assistant.

### Key Features
- Personalized learning recommendations.
- Progress tracking.
- Difficulty levels.
- Learning dashboard.
- Improved security and reliability.

### Success Criteria
Users can study topics, track their progress, and receive personalized learning support.
